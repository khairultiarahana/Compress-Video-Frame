Yang perlu diketahui sebelum kompresi

Mode cepat memakai WebCodecs melalui Mediabunny, dengan encoder hardware jika browser/perangkat mendukung. Kompresi tidak harus menunggu video diputar secara real time. Kecepatan tetap bergantung pada durasi, codec, resolusi, dan perangkat. Jika codec tidak didukung, pilih mode FFmpeg secara manual; mode ini lebih lambat dan memuat mesin sekitar 32 MB. Semua pemrosesan tetap lokal tanpa upload video. Jalankan melalui localhost atau HTTPS. Target MB merupakan estimasi, bukan jaminan ukuran persis; periksa ukuran aktual dan preview hasil. MB = 1.000.000 byte. Saat browser mendukung dialog Simpan, aplikasi dapat mengonfirmasi file telah ditulis; untuk download biasa, periksa daftar Downloads browser.
